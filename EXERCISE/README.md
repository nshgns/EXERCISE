# EXERCISE - Ürün Yönetim Sistemi

## 📋 Proje Hakkında
Bu proje, ASP.NET Core MVC kullanarak geliştirilmiş bir e-ticaret/ürün yönetim sistemidir.

## 🛠️ Teknolojiler
- **Framework:** ASP.NET Core (.NET 9)
- **Veritabanı:** SQL Server (LocalDB)
- **ORM:** Entity Framework Core
- **Authentication:** Cookie Authentication

## 📦 Kurulum

### Gereksinimler
- .NET 9 SDK
- SQL Server (LocalDB)

### Adımlar
1. Repository'yi klonla: `git clone https://github.com/nshgns/EXERCISE.git`
2. Bağımlılıkları yükle: `dotnet restore`
3. Uygulamayı çalıştır: `dotnet run`

## 🎯 Özellikler
✅ Kullanıcı Kaydı ve Giriş  
✅ Ürün Listeleme  
✅ Sepet Yönetimi
